**A note about contribution records:** project work includes planning, research, testing, meetings and documentation as well as code. Not all of that work appears as a Git commit. The status column is deliberately specific about what can currently be checked in this repository; it does not mean that work outside Git has not taken place.

Pull requests and merged changes provide a clear way to add evidence as the team continues working. See [CONTRIBUTING.md](CONTRIBUTING.md) and [docs/TEAM_CONTRIBUTIONS.md](docs/TEAM_CONTRIBUTIONS.md).
