# MeetCite version history

MeetCite uses **semantic versioning**: MAJOR.MINOR.PATCH.
* **MINOR** goes up when features are added.
* **PATCH** goes up for fixes.
* **1.0.0** is reserved for the first release that has been tested with real users, which means after the ethics
  approval and the user study.

## About the existing tags

## 0.6.0: ready for ethics review (21 Oct 2026)
* **Changed.** The user study no longer records anyone. Volunteers review one pre-processed public AMI meeting with
  code-only test accounts. The consent form and protocol were updated to match.
* **Commit.** `7ba24b3`.
* **Limitations.** The study cannot start until ethics approval is granted.

## 0.5.0: what needs attention (21 Oct 2026)
* **Features.**
  * A home panel ranks meetings by what needs doing: failed processing, overdue actions, changed decisions,
    unchecked claims, unowned actions, and actions due soon.
  * A "Needs attention" filter.
  * Links straight to the right tab.
* **Technical.** Two new meeting fields, `review_needed_count` and `change_count`.
* **Fixes.** An ambiguous list name in a browser test.
* **Testing.** 1 new backend test and 5 new unit tests. The full suite passed: 85 backend, 34 unit, 6 browser.
* **Commit.** `9bc1d36`.

## 0.4.0: every screen (20 to 21 Oct 2026)
* **Features.** Swipeable card rows and a shorter landing page on phones.
* **Fixes.**
  * The dashboard overflowed by up to 355 px on phones.
  * Series actions were cramped.
* **Testing.** A new browser test checks every page at 11 widths, from 320 to 1920 px.
* **Commits.** `c76c80e`, `ec742a1`.

## 0.3.0: first deployment (20 Oct 2026)
* **Features.**
  * Live at https://meetcite.com.ng with automatic HTTPS.
  * Nightly backups (7 daily, 4 weekly), with a tested restore.
  * All five members credited on the site.
  * The README rewritten.
* **Commits.** `bed2b35`, `48087a7`, `ca1a666`.
* **Limitations.**
  * Small single server: 1 CPU and 2 GB of memory.
  * No monitoring yet.
  * No real meeting processed yet.

## 0.2.0: MeetCite (13 Oct 2026)
* **Changed.** Renamed from MeetMind after another product with that name was found.
* **Fixes.** Group documents and recordings are now kept out of the server package.
* **Commits.** `38b95de`, `d44f8e7`.

## 0.1.0: first prototype (13 Oct 2026)
* **Features.**
  * Upload and record meetings.
  * Speaker-labelled transcripts.
  * C1 and C2 minutes, decisions and action items.
  * The AI check (supported, partly supported, not supported).
  * Series memory and live captions.
  * Exports and calendar reminders.
  * A dashboard and the mascot.
  * Local and cloud AI modes.
* **Testing.** pytest, Vitest and Playwright test suites, and CI.
* **Commit.** `cc4aaca`.
* **Note.** This release contains five days of work done before the repository existed. See the
  [development log](DEVELOPMENT_LOG.md).
