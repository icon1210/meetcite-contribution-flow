# MeetCite contribution activity

The **Show merged contribution** GitHub Actions workflow writes a contribution card to the run summary whenever a pull request is merged. It names the pull request author and links the merged work. Add a row to the table below in the same pull request when recording project contributions. A merged PR is one visible record of contribution, not a measure of someone's overall effort.

The source project arrived as a ZIP without Git history. GitHub records the account that performs the repository bootstrap, but that does not establish authorship of the existing application. Work becomes attributable through reviewed pull requests merged after this workflow is enabled.
